# Heatmap Grasping project page

This is a plain HTML/CSS GitHub Pages starter modeled on the structure of modern robotics project pages. The page identifies the project with the MIT Biomimetics Lab and intentionally contains placeholders for your own text, figures, and videos.

Open `index.html` directly in a browser while editing, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

The planned remote repository is `andrewjnguyen21/heatmap-grasping`.
