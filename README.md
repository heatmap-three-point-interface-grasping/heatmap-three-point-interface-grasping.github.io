# Paper Website

Project page for "Steerable and Reactive Grasping Through Modular Design with a Three-Point Interface." Plain HTML/CSS, styled to match the FREE Lab wall-climbing-robot project page.

Serve locally with `python3 -m http.server 8000` from this directory.
